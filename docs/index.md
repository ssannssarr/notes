# CITK Notes Hub

A small PWA I built to keep our first-semester notes, practicals, and question papers in one place.

It is still a work in progress. I add material whenever I get notes or when useful resources are available.

## Available now

- **DCH101 — Chemistry**
  - Electrochemistry
  - Fuels and combustion
  - Organic chemistry
  - Lubricants
  - Lab practicals

- **DHS101 — English**
  - Communication and language
  - Communication process

- **DMA101 — Mathematics**
  - Complex numbers
  - Partial fractions

- **DPH101 — Physics**
  - Elasticity
  - Gravitation and force

- **Mid-semester question papers**
  - DMA101

## Use it

Use the sidebar to browse subjects, or use search if you already know the topic name.

    This website is maintained by one student for classmates. Notes may be updated, corrected, or expanded over time.

## Built with

- MkDocs Material
- GitHub Pages
- PWA support for easier access on mobile
Thus
For full documentation visit [mkdocs.org](https://www.mkdocs.org).

## Commands

* `mkdocs new [dir-name]` - Create a new project.
* `mkdocs serve` - Start the live-reloading docs server.
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.
