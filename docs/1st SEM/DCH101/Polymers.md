# Polymer

## 1. Based on monumer under **Polymer** are of two type:

| Homo-Polymer     | Co-Polymer        |
| ---------------- | ----------------- |
| [ A - A - A ]    | [ A - B - A - B ] |
| `eg` PE, PKC, PP | `eg` Nylon 6, 6   |
### Differene between Co-Polymer & Homo-Polymer:

| HOMO-POLYMER                      | CO-POLYMER                       |
| --------------------------------- | -------------------------------- |
| 1. Monumers are identical         | 1. Monumers are non-identical    |
| 2. Generally are addition polymer | 2. This are condensation polymer |
| 3. This are of only one type      | 3. This are of 4 types           |
