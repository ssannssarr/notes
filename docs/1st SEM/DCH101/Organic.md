# Organic Chemistry Notes

## 1. Isomerism

### Isomers
- Compounds having the **same molecular formula** and **same molecular mass**, but different arrangements/structures.
$$
\boxed{
 \text{
Compounds having same moleculer formula but with diff structural formula.
 }
}
$$

### Types of Isomerism
- **Structural isomerism**
- **Positional isomerism**
- **Functional isomerism**

### Structural Isomerism
Example:
- Molecular formula: **C₄H₁₀**
- Different carbon arrangements are possible.

### Positional Isomerism
Example:
- Molecular formula: **C₃H₈O**
- `CH₃–CH₂–CH₂–OH` → propanol-1
- `CH₃–CH(OH)–CH₃` → propanol-2

### Functional Isomerism
Example:
- `CH₃CH₂OH` → ethanol / ethyl alcohol
- `CH₃–O–CH₃` → ether

## 2. Stereoisomers

Stereoisomers are divided into:

- **Geometrical isomers**
- **Optical isomers**

### Geometrical Isomerism
- Occurs in **alkenes**.
- Two forms:
  - **cis**
  - **trans**

Examples:
- cis-but-2-ene
- trans-but-2-ene

### Optical Isomerism
- **Lactic acid** is given as an example of a chiral compound.

## 6. Carbocyclic Compounds

Carbocyclic compounds include:

### (a) Aliphatic
- Open-chain compounds.

### (b) Aromatic

Examples:

- **Benzene (C₆H₆)**
- **Naphthalene**
- **Anthracene**

---

## 7. Heterocyclic Compounds

If an atom such as **oxygen, nitrogen, phosphorus, or sulphur** is present in the ring, it is classified as a **heterocyclic** compound.

Examples:

- **Pyridine**
- **Pyrrole**
- **Furan**
- **Thiophene**

# 15. Naming Branched Alkanes

### Basic Steps

1. Find the **longest carbon chain**.
2. Number the chain.
3. Give substituents the appropriate numbers.
4. Name the substituents.
5. Combine the locants + substituent name + parent-chain name.

### Examples from the Notes

- 4-methylhexane
- 3-methylhexane
- 2,3-dimethylbutane
- 3,4-dimethylheptane
- 3,4,5-trimethylheptane
- 3,4,5-trimethylhexane

# 16. Alkyl Groups

An alkyl group is formed by removing one hydrogen from an alkane.

| Alkane | Alkyl Group |
|---|---|
| Methane | Methyl → CH₃– |
| Ethane | Ethyl → C₂H₅– |
| Propane | Propyl → C₃H₇– |
| Pentane | Pentyl |
| Hexane | Hexyl |

### General Idea

**Alkane − H → Alkyl group**
