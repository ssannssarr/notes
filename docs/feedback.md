# Feedback

Found a mistake, missing something, or have an idea for CITK Notes Hub?

Tell me about it. Your feedback helps keep the notes useful and accurate for everyone. 📝

## What do you want to report?

### 🐛 Report a mistake

If something in a note is wrong, unclear, or broken, please open a GitHub issue.

[Report a mistake →](https://github.com/ssannssarr/notes/issues/new?template=mistake.md)

When reporting a mistake, include:

- **Subject:** e.g. DMA101
- **Topic:** e.g. Complex Numbers
- **What is wrong?**
- **What should it be?** (if you know)
- **Page or section:** if possible

---

### 💡 Suggest something

Want another chapter, practical, question paper, feature, or useful resource?

[Make a suggestion →](https://github.com/ssannssarr/notes/issues/new?template=suggestion.md)

You can suggest things like:

- Missing chapters or topics
- Previous-year question papers
- Lab practicals
- Better explanations
- Useful features
- Other study resources

---

### ⭐ General feedback

You can also open a normal issue and tell me what you think about the website or notes.

[Send feedback →](https://github.com/ssannssarr/notes/issues/new)

## Before you submit

Please search existing issues first. Someone may have already reported the same thing.

> CITK Notes Hub is maintained by one student, so updates may take some time. Thanks for helping improve it.

[View existing feedback and issues →](https://github.com/ssannssarr/notes/issues)
